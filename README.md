# 共创项目簿

这是 Leona 当前创意项目的公开清单，包含小游戏、数字人文、文化体验、空间交互与注意力工具。

网页内容包括：

- 12 个项目的方向与下一步
- 按状态筛选和关键词搜索
- Leona 微信、猴击俱乐部吼叫群及共创群二维码

## 在线访问

启用 GitHub Pages 后，可通过仓库首页提供的网址直接访问。

## 本地查看

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动本地服务器。

## 源项目

`app/` 中保留了完整的 React / vinext 版本；仓库根目录的 `index.html` 是用于 GitHub Pages 的独立静态版本。
